# WordLoop 课程内容总标准

本文件应作为 Prompt 0—3 的公共规则注入系统提示词或上下文。

## 一、产品内容定位

WordLoop 课程以“跟读 16 个高频、自然、实用的英语句子”为核心。

课程不是词典例句合集，也不是语法展示。每门课程必须让学习者在完成后获得一种明确、可描述的口语能力。

目标学习者：以中文为母语、希望提升真实英语口语输出能力的成年人。

默认语言变体：自然、现代的美式英语。避免过度俚语化、地域化和网络化。

## 二、现实使用测试

每一个最终句子都必须通过以下测试：

1. 能明确说明学习者可能在什么情况下说出这句话；
2. 句子本身值得被重复朗读和掌握；
3. 不是为了满足结构、语法点、难度数量或句子数量而存在；
4. 删除后如果课程完全不受影响，则需要重新判断它是否是填充句；
5. 能够独立呈现和朗读，不依赖上一句才能成立。

课程结构服务于沟通目标，而不是让沟通内容服务于课程结构。

## 三、课程类型判定

### 1. `scenario_interaction`

用户需要在一个现实情境中完成具体任务。

课程难度主要来自：

- 任务步骤数量；
- 是否需要补充信息；
- 是否需要修改需求；
- 是否需要处理限制、错误或协商方案。

### 2. `communication_skill`

用户需要掌握一种跨场景沟通行为。

课程难度主要来自：

- 直接程度与礼貌程度；
- 语气控制；
- 是否需要补充理由；
- 是否需要让步、保留立场或处理分歧。

### 3. `topic_expression`

用户需要围绕一个主题描述自己或表达观点。

课程难度主要来自：

- 细节丰富度；
- 原因解释；
- 时间变化与对比；
- 例外、取舍、让步；
- 观点的完整性。

当一个题目可归入多种类型时，必须根据主要学习成果只选择一种主类型，禁止用“混合型”回避判断。

## 四、课程等级定义

课程等级首先由表达任务决定。

### A2

学习者主要能够：

- 命名和简单描述；
- 表达直接需求；
- 陈述时间、地点、数量、频率和偏好；
- 回答常见的直接问题；
- 使用高频短句完成基本交流。

### B1

学习者主要能够：

- 补充具体细节；
- 解释原因；
- 描述经历和变化；
- 比较过去与现在或两个选择；
- 处理普通问题；
- 用若干句组织一个完整意思。

### B2

学习者主要能够：

- 表达细微态度；
- 讨论利弊和取舍；
- 处理条件、限制与分歧；
- 表达保留、让步和例外；
- 组织更成熟、完整的个人观点。

禁止仅通过低频词、抽象词或长句人为提高等级。

## 五、单句难度维度

单句难度至少从以下五方面判断：

1. **词汇难度**：高频程度、抽象程度、新词数量、固定搭配难度；
2. **句法难度**：简单句、并列、原因/条件/时间从句、多层结构；
3. **表达任务难度**：事实、需求、原因、比较、取舍、保留、让步；
4. **信息负载**：学习者需要同时保留几个信息单位；
5. **口语负载**：长度、缩写、连读密度、自然意群、难发音组合。

词数只是约束之一，不能单独代表难度。

## 六、默认难度分布

每门 16 句课程默认使用：

```text
entry：3 句
目标等级 base：4 句
目标等级 core：6 句
stretch：3 句
```

对应范围：

```text
A2：A2- / A2 / A2+
B1：A2+ / B1 / B1+
B2：B1+ / B2 / B2+
```

难度应总体上升，但采用波浪式递进：

- 前几句容易开口；
- 中间引入并反复训练核心表达；
- 难句后安排适当回落；
- 不连续堆叠过多挑战句；
- 最后一两句强调完整表达，而非纯粹制造最高难度。

## 七、一次只提高一个主要难度维度

相邻句子递进时，优先只增加一个主要因素：

- 增加一个细节；
- 增加一个原因；
- 增加一个对比；
- 增加一个条件；
- 增加一个新的核心表达；
- 稍微增加长度。

禁止同时大幅增加词汇、句法、信息数量、抽象程度和句长。

## 八、核心表达设计

每门课程选择 3—5 个真正值得掌握的核心表达块。

每个核心表达应：

- 在真实交流中高频；
- 可以迁移到其他场景；
- 在课程内重复 3—5 次；
- 每次承担不同沟通作用，而不是只替换名词。

有价值的重复：同一表达用于不同语义、语气或任务。

无价值的重复：仅替换一个名词、饮料、地点或时间。

## 九、句子写作标准

最终句子必须：

- 使用自然、现代、口语化的英语；
- 优先使用自然缩写，如 `I'm`、`I'd`、`don't`；
- 含义清晰，适合单句跟读；
- 原则上只承载 1—2 个主要信息单位；
- 避免明显教材腔和书面腔；
- 避免无必要的生僻词、专有名词和品牌；
- 避免复杂地址、电话号码、金额和日期；
- 避免括号、斜杠、破折号及异常符号；
- 避免依赖虚构人物关系或戏剧化经历；
- 中文翻译自然、准确，不逐词硬译。

参考词数范围仅作产品约束：

```text
A2：通常 5—10 词
B1：通常 8—15 词
B2：通常 10—18 词
```

句子超过范围并非绝对错误，但必须有明确的表达必要性。

## 十、内容边界

除非课程主题明确需要，否则避免：

- 过强文化背景知识；
- 政治、宗教和敏感争议；
- 诊断性医疗建议；
- 复杂法律和金融建议；
- 刻板印象；
- 过于私密或令人不适的内容；
- 依赖某个特定国家流程才能成立的细节。

## 十一、课程整体自检

每门课程最终必须能够回答：

1. 学习者学完后具体能说什么？
2. 哪 3—5 个表达被真正练熟？
3. 16 句话是否形成一条可感知的能力递进？
4. 是否存在任何为了凑数而存在的句子？
5. 是否有难度突然跳升或后半段全部变成长句的问题？
