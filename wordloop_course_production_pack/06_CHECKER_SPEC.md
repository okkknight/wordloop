# WordLoop 确定性检查程序需求

本文件用于指导 Codex 实现候选句生成后的检查程序。

## 一、职责边界

检查程序只负责可以确定计算和验证的问题，不负责：

- 判断英语是否自然；
- 精确判断 CEFR 等级；
- 判断现实实用性；
- 判断课程是否值得学；
- 判断高相似句是否属于有价值重复。

这些问题交给 Prompt 3 和人工审核。

## 二、输入

程序至少接收：

- 课程蓝图 JSON；
- 候选句 JSON；
- 对应 JSON Schema；
- 可选的全局配置。

## 三、输出

输出结构化检查报告，至少包含：

```json
{
  "valid": false,
  "summary": {
    "errorCount": 0,
    "warningCount": 0
  },
  "errors": [],
  "warnings": [],
  "metrics": {}
}
```

错误代表必须修复后才能进入 Prompt 3；警告代表交由 Prompt 3 判断。

## 四、必须实现的检查

### 1. JSON Schema

- 蓝图是否符合 schema；
- 候选句是否符合 schema；
- 必填字段是否存在；
- 字段类型是否正确；
- 枚举值是否合法。

### 2. 数量与槽位完整性

- 是否正好存在 20 个槽位；
- 槽位编号是否为 1—20；
- 是否有缺失或重复槽位；
- 每个槽位候选数是否符合配置；
- 候选句是否关联有效槽位。

### 3. 词数

使用统一英文分词规则计算词数：

- 缩写如 `I'm` 计为 1 词；
- 连字符词建议计为 1 词，并记录实现规则；
- 纯标点不计词数。

检查每个候选句是否在对应槽位的 `wordCountMin` 和 `wordCountMax` 范围内。

同时校验模型自报词数是否与程序计算一致。

### 4. 标点与异常字符

检查并报告：

- 多余换行；
- 双空格；
- 连续异常标点；
- 括号、斜杠、反斜杠；
- 破折号；
- 非预期 emoji；
- 无法解释的特殊字符；
- 英文句子结尾异常；
- 中文翻译为空或明显只包含英文。

具体禁止字符应可配置。

### 5. 完全重复与规范化重复

对英文句子执行规范化：

- 转小写；
- 去除标点；
- 合并空格；
- 可选地展开或统一常见缩写。

检查：

- 完全重复；
- 规范化后重复；
- 同一槽位的两个候选是否相同。

完全重复应为 error。

### 6. 高相似度标记

建议至少实现两类相似度：

1. 词集合 Jaccard 或 token overlap；
2. 编辑距离或序列相似度。

可选增加句向量余弦相似度，但第一版不是必须。

输出相似句对、分数、所在槽位。

高相似度默认为 warning，不自动删除。

阈值应配置化，例如：

```json
{
  "tokenSimilarityWarning": 0.82,
  "sequenceSimilarityWarning": 0.88
}
```

### 7. 指定核心表达覆盖

根据蓝图检查：

- `requiredChunks` 是否出现在候选句中；
- 每个核心表达的计划覆盖槽位是否有对应候选；
- 核心表达总出现次数是否达到最低要求。

匹配应支持：

- 大小写忽略；
- 标点忽略；
- 可配置的占位表达，例如 `I used to..., but now...` 不能只做纯字符串匹配。

第一版可以允许蓝图提供 `chunkMatchers`，包括正则或关键词序列。

### 8. 粗略分句数

依据逗号、分号、连接词和从属标记进行启发式统计，检查是否明显超过 `maxClauses`。

由于无法完全准确，超过时标记 warning，而非直接 error，除非结构明显异常。

### 9. 信息字段一致性

检查：

- `usedChunks` 是否为空；
- `estimatedDifficulty` 是否为允许值；
- `slot`、`section` 等是否与蓝图一致；
- 模型自报 `clauseCount` 和程序粗测是否差异过大；
- 英文和中文字段是否为空。

### 10. 难度配额结构检查

程序不判断句子真实 CEFR，但应检查：

- 蓝图中的难度分布总数是否为 20；
- 每个槽位难度档位是否与蓝图曲线一致；
- 最终候选集合是否覆盖全部难度槽位；
- 是否出现蓝图禁止的连续 stretch 槽位；
- 相邻槽位是否出现配置上禁止的难度跨级。

## 五、建议的错误与警告分类

### Error

- Schema 不合法；
- 槽位缺失或重复；
- 候选数量不足；
- 英文或中文为空；
- 完全重复；
- 必需核心表达完全缺失；
- 词数严重超限；
- 非法难度枚举。

### Warning

- 高相似度；
- 轻微词数超限；
- 可能分句数超限；
- 可能存在机械替换；
- 标点异常；
- 自报词数与程序计算不一致；
- 核心表达出现过多；
- 连续句开头高度相同。

## 六、建议实现形式

建议使用：

- TypeScript 或 Python；
- JSON Schema 校验库；
- 单元测试；
- CLI 命令；
- 输入输出文件路径参数；
- 非零退出码表示存在 error；
- 同时输出 JSON 报告和便于人工阅读的终端摘要。

示例命令：

```bash
wordloop-check \
  --blueprint outputs/course-blueprint.json \
  --candidates outputs/candidates.json \
  --report outputs/checker-report.json
```

## 七、暂时不要实现

第一版不要把以下内容做成硬规则：

- 依赖词表自动判定精确 CEFR；
- 用词数直接决定难度；
- 自动删除高相似句；
- 自动判断英语自然度；
- 自动判断现实使用价值；
- 自动替换或修改句子。
